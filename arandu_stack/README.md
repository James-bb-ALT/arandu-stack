# Arandu Stack

Painel central para ativar, parar, reiniciar e configurar Wake, STT, NLU, Decision,
LLM e TTS. Instale os módulos desejados da mesma origem deste painel.

Abra pela interface do Home Assistant. Frases personalizadas são atalhos exatos
e precisam da integração NLU distribuída no repositório.
