# Vozes incluídas

## Arandu

Fine-tune local do projeto, exportado do checkpoint salvo na época 145.
Distribuído sob Apache-2.0, preservando a atribuição da base Faber Medium.
Consulte ARANDU_MODEL_CARD.md para origem, exportador e limites da validação.

## Faber Medium

Modelo publicado por rhasspy/piper-voices. O repositório upstream declara MIT
no README preservado nesta pasta. O MODEL_CARD identifica o dataset como CC0.
O modelo base e os avisos não foram renomeados. O hash do ONNX incluído coincide
com o SHA256 publicado no repositório de origem.

Origem fixa: https://huggingface.co/rhasspy/piper-voices/tree/5041a7a49ae5b3a0f30e6837769eb03fdbb231bd/pt/pt_BR/faber/medium
