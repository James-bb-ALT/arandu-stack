# P14 Noise channel

This crate is the shared Rust transport boundary for the add-on adapter and
the Home Assistant companion helper. It fixes the protocol profile to
`Noise_NNpsk0_25519_ChaChaPoly_BLAKE2s` through Snow 0.10.0. It does not
implement a cryptographic primitive or expose Snow state.

## Source layout

The manifest expects the admitted, read-only P13 projection at:

```text
vendor/snow-0.10.0
vendor/chacha20-0.9.1
vendor/poly1305-0.8.0
```

The promoted root vendor directory and offline Cargo source replacement supply
the remaining exact P13 registry projection. Before this crate becomes a
product dependency, the integrating change must:

1. add `crates/noise-channel` to the root workspace members;
2. move this manifest's `chacha20` and `poly1305` patch entries to the root
   `[patch.crates-io]` table, because Cargo ignores member-level patches;
3. force and check `chacha20_force_soft`, `poly1305_force_soft`, and
   `curve25519_dalek_backend="serial"` for every build of this crate;
4. generate the root lock offline and verify Snow 0.10.0 plus the exact
   23-package P13 closure; and
5. run the native read-only-source amd64 and aarch64 admission gates.

The exact paths intentionally do not fall back to a registry or network
source.

The isolated crate tests can instead link directly to the immutable rlibs
generated by the P13 capability projection. That test path does not modify or
copy the projection.

## Wire contract

Handshake messages are independently bounded to 128 bytes. Transport frames
use a two-byte big-endian ciphertext length followed by at most 65,535 bytes
of Noise ciphertext. The encrypted plaintext header binds the frame version,
epoch, connection nonce, message direction, frame kind, exact sequence, and
payload length. The maximum application payload is 65,455 bytes.

Sequences start at zero, must be exact and gap-free in each direction, and
never use `u64::MAX`. Each direction deterministically rekeys after every
1,048,576 accepted frames. A close frame closes one direction; after both
directions close, Snow transport state is dropped.

## Secret lifecycle

Pending handshake state overwrites Snow's stored PSK slot before transition,
abort, or drop. `NoiseChannel::close` immediately drops Snow transport state;
the selected ChaCha20-Poly1305 provider zeroizes its owned transport key on
drop. The wrapper also performs a best-effort overwrite of its owned handshake
message, encrypted-frame, and received-plaintext buffers on drop.

Snow does not expose complete zeroization for every handshake, allocator,
stack, or register copy. This crate therefore makes no broader erasure claim.
The dedicated peer process, locked-memory, no-dump, provisioning, and process
termination controls required by ADR-0022 remain mandatory.
